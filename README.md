# libchstr

A collection of useful tools to work with strings in C (Linux).

## No AI

This repository contains functions I’ve found useful while learning C. Although LLMs can be incredibly helpful for learning, using them to generate code while you’re learning a programming language defeats the purpose. That’s why none of the code here was generated by an LLM.

## Build

For optimized build, run:

```
meson setup -Dbuildtype=release -Db_ndebug=true release
meson compile -C release
```

For everything else - see the [Makefile](Makefile).
